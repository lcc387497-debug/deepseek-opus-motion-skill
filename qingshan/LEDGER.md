# 青山 · 设计账本

风格来自提示词原文（水墨、色值、字体、分镜、禁止项）。`editorial-ink` 只提供机制：毛边滤镜、干笔雾气、印章落点、五声音阶。种子里的茶色 `#A7774A` 不用，因为原文规定印章红是唯一强调色。

循环静帧：第 0 秒和第 20 秒都是悬在 (960, 420) 的同一滴墨。落下发生在 0.12–0.75 秒，落点 (960, 540)。收束后再升回悬停点，这样两帧都静止且相同。这是为「第 20 秒 = 第 0 秒」补上的闭合，不是原文另写的一拍。

## 规格 S

- S01 20 秒循环
- S02 茶叶品牌「青山」
- S10 宣纸 `#F3EEE3`
- S11 墨 `#1A1814`，浓淡用透明度
- S12 印章红 `#B8322A`，全片只有这一处红
- S13 纸纤维
- S14 笔触毛边，不用光滑矢量线
- S15 标题思源宋体 Noto Serif SC，竖排，字重 900
- S16 小字思源黑体 Noto Sans SC，25 px，字距 0.1 em
- S17 1920×1080，60 fps
- S18 镜头固定
- S19 静止元素离左右 ≥150 px，离上下 ≥90 px
- S20 80 BPM
- S21 舒缓，不回弹
- S22 看字可停留 1–2 秒
- S23–S27 分镜五段，见 `src/spec.ts` 的 `T`
- S28 禁止渐变、发光、粒子、镜头晃动、淡入淡出、光滑矢量线、emoji、印章以外的红色

## 形变 X

- X01 墨滴落下：同一滴从 (960, 420) 拉长再压扁，落到 (960, 540)
- X02 墨滴分成三层远山：`chain()`，点从墨滴长出，远淡近浓，从左到右
- X03 近山收拢成茶叶：同一组 96 点收到叶片
- X04 叶脉一笔：`drawOn`，纸色留白，好让它在浓墨叶片上看得见
- X05 远山、中山收成雾带并向右飘
- X06 茶叶旋落进杯：同一组点转到杯口
- X07 茶杯一笔勾出，收束时改成实心墨形再收入墨滴
- X08 三圈涟漪由半径胀开再向内收到 0，不改透明度
- X09 「青山」逐字用遮罩写下
- X10 方印按下，接触时雾气停一拍，无回弹
- X11 小字逐字写出
- X12 涟漪向内收回
- X13 杯、叶、标题、印、小字依次移向画面正中并缩小，源对象消失后只剩墨滴
- X14 墨滴升回 (960, 420)，与第 0 帧相同

标题和小字没有拆成字形轮廓再逐点变形。起步项目没有中文字形轮廓。它们本身平移并缩小进墨滴，透明度保持到被吸收。

## 元素 E

- E01 宣纸：底色、细粒、长纤维
- E02 墨滴：毛边圆点，全片的载体
- E03 三层山：远 / 中 / 近，透明度 0.16 / 0.40 / 0.93
- E04 茶叶：尖、腹、蒂，加一笔叶脉
- E05 雾：山收成的扁带，加三条干笔，向右慢移
- E06 茶杯：椭圆口、腹、足，一笔
- E07 三圈涟漪
- E08 竖排「青山」
- E09 红色方印「青山」
- E10 小字「一叶 · 一山 · 一盏」
- E11 配乐：ink 调色，D2 长音，五声拨弦，水滴、刷笔、印章叩击
